# My Apps Hub v1

Standalone PWA home for:
- Birthday Reminder
- Naam Jaap Counter

Existing applications are not modified.

The Hub stores only the optional display name locally. When an app is opened,
the name is passed in the URL fragment using the existing `suite_name` / `suite_enter`
handoff convention already implemented by the two applications.

## Deployment
This folder can be deployed as a static GitHub Pages site or any static web host.
